# dica-dio-agente
Como clonar e rodar o DIO Agent no Google Antigravity em 1 passo.

DIO Agent no Google Antigravity: Guia Rápido

Este projeto traz uma dica prática para estudantes da DIO que querem configurar seu mentor de IA sem complicações.

O Problema: Muitos alunos travam tentando instalar o Git no computador ou baixando pastas zipadas.

A Solução em 1 Passo: Se você usa o Google Antigravity, basta colar o comando abaixo direto no chat da IA:

git clone https://github.com/digitalinnovationone/dio-agent.git

O próprio Antigravity reconhece o comando, configura o que precisa e cria a pasta com o seu mentor pronto para estudar!
